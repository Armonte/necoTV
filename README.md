# necoTV

Bug reports and feature requests for **necoTV**: live spectating, the replay viewer, clips, chat and the radio.

**[Open an issue](../../issues/new/choose)**

- **Bug:** say what you did, what you expected, and what happened. Include the page link (replay / live / clip), your device and browser, and a screenshot or short video if you can.
- **Feature:** say what you want to do and why. A sketch or an example from another site helps.

Search the existing issues first. If yours is already there, add a 👍 or a comment instead of a new issue.
